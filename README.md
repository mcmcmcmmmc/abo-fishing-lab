# 潮间 · 阿波钓法可视化训练室

一个本地运行、无需注册或后端的交互教学 Web App。采用 React + TypeScript + Vite + SVG。

## 运行

需要 Node.js 20.19+ 或 22.12+（本次验证环境：Node 25.8.1）。

```bash
cd '/Users/panzijie/Projects/knowledge/钓鱼/abo-fishing-lab'
npm install
npm run dev -- --port 5173 --strictPort
```

打开 http://127.0.0.1:5173/ 。依赖已经安装时可以跳过 `npm install`。停止服务：终端按 Ctrl+C。

推送到 GitHub 的 `main` 分支后，`.github/workflows/deploy-pages.yml` 会自动构建并发布到 GitHub Pages。构建会按仓库名生成正确的 Pages 资源路径，本地运行仍从域名根目录加载资源。

```bash
npm run build   # 类型检查 + 静态生产构建，输出 dist/
npm test        # 模型和训练逻辑测试
npm run preview # 本地预览生产构建
```

应用运行不请求外部 API、不加载 CDN 字体或远程图像。首次安装依赖需要 npm 网络访问；已经安装后可离线开发和构建。生产构建需用静态 HTTP 服务打开，不支持直接双击 dist/index.html。

## 已实现：Phase 1–5 MVP

1. **钓组拆解**：11 个可点击部件，功能、物理变量、因果链；主要部件提供移除后的示意和解释。
2. **入水状态**：第一视角、俯视、剖面共用同一状态；13 个环境 / 钓组参数；30 Hz 固定步长；暂停、重抛、力箭头、Debug。
3. **阿波实验室**：配重平衡、露出比例、基准配置对照；四类可解释指标，没有神秘分数。
4. **漂相观察室**：6 种真鱼讯、9 种干扰 / 非目标吃口；水下真相、事件节点、可拖动时间轴、0.5× / 0.25× 回放。
5. **判断训练**：随机 8 秒片段，不连续重复；提交前隐藏水下；完整播放后才能判断；原因与行动分别评价；允许保留判断；本机学习记录。

六个学习区均有导航。**水流与诱饵、综合实战尚未实现**，入口明确标为 Phase 6 / 7。未实现撒饵粒子、三种鱼行为状态机、抛投控线、8 个关卡、整局回放或自由实验室解锁机制。不要把漂相教学回放当成已完成的整局游戏。

## 试用路线

- 钓组拆解：关闭棉线结，理解半游动钓棚如何失去限位；再试关闭咬铅。
- 入水状态：提高侧风，比较漂饵偏移；切换钓组参数增加咬铅；尝试浅水与过深钓棚。
- 配重实验：记下对照配置，将咬铅调到 3 g 等效，看剩余承载量变负。
- 漂相识别：比较“快速下沉”和“主线突然绷紧”；点击水下真相，拖到 2.7 秒看传递阶段。
- 判断训练：先观察完整片段，再选原因和扬竿 / 等待，提交后逐项复盘。

## 模型与内容边界

- 结构采用半游动示例，移除棉线结不等于所有钓法失效；全游动需另行控线。
- 浮力输入为**净等效承载量**；咬铅、钩饵、连接件为水中等效负载。不能按这些值采购真实型号。
- 露出比例用等截面浮体近似，不是所绘纺锤体的精确高度百分比。
- 水层速度按统一配置中的权重混合潮流与层流；风通过表层线的经验耦合改变漂移。倾角为准静态近似；下沉速度为经验关系。
- 图中横向位移为教学放大，侧剖面是二维投影。三视图共享状态，但画面不具有测绘尺度精度。
- 漂相是预编排的合成教学情境，不是现场录制或生态学模型。同一种动作可能有多个原因；观察以外的信息不足时，等待与保留假设是合理选择。
- 本轮依据用户提供的产品提示词组织教学内容，**未经渔具标定、真实海钓试验或钓法专家审核**。实际浮力 / 阻力系数、鱼行为和触礁细节仍需后续验证。

## 代码入口

- `src/physics/simulationConfig.ts`：物理常数、默认参数、控件约束。
- `src/physics/model.ts`：负载、浮力余量、下沉、流层混合与倾角。
- `src/simulation/engine.ts`：状态更新与固定时钟。
- `src/simulation/signals.ts`：可重复采样的教学信号。
- `src/data/equipment.ts` / `signals.ts`：部件解释与 15 个情境。
- `src/components/`：拆解器、SVG 三视图、实验、回放和训练界面。
- `src/training/`：题目生成、分项评价、本地进度数据校验。
- `src/fish/` / `scenarios/`：下一阶段边界说明。

学习进度使用 localStorage `tide-abo-progress-v1`。存储不可用或数据损坏时应用仍可运行。“已体验”表示做过交互，不代表学会。当前切换模块会重新开始该模块的实验，学习记录不受影响。

原始完整需求见 `PRODUCT_BRIEF.md`；实施范围见 `DEVELOPMENT.md`；本次验证见 `VERIFICATION.md`。
